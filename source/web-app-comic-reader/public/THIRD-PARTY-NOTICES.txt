libarchive.js  (https://github.com/nika-begiashvili/libarchivejs)  — MIT
----------------------------------------------------------------------
The app uses libarchive.js 2.0.2. Its page-side code is bundled into the app.
Its worker (vendor/libarchive/worker-bundle.js) is bundled from the same
package's sources, unchanged, around a WebAssembly build of libarchive made
for this app (see the next section) and a few lines of this app's own code
that pass the worker's ?v= query on to the request for the .wasm file. The
C wrapper compiled into that module (native/libarchive/libarchivejs/main.c
in the source package) is also from
libarchive.js 2.0.2, with seven changes marked in the file: only the RAR,
7z and zip readers are enabled, the previous reader is freed when the next is
opened, an allocation is checked and zeroed, a buffer is freed when a read
fails, a freed reader is no longer asked for its error string, zip
checksums can be left uncompared for a zip the app has decrypted, and an
entry is read to its end, which is where its checksum is compared.

The prebuilt WebAssembly module that libarchive.js itself distributes is not
used, because it includes OpenSSL 1.0.2.

7-Zip  (https://www.7-zip.org)  — LGPL-2.1-or-later
----------------------------------------------------------------------
7-Zip Copyright (C) 1999-2026 Igor Pavlov.

vendor/sevenzip/sevenzip.wasm and sevenzip.mjs are parts of 7-Zip 26.06,
compiled to WebAssembly from unmodified sources. The reader uses them for
password-protected archives only: to read 7z, and to decrypt RAR and the AES
entries of zip for its other decoders to read. What is compiled:

  - the files 7-Zip's own extract-only 7z library is built from: the 7z
    container, the LZMA, LZMA2, PPMd, Deflate, BZip2 and Copy decoders, the
    BCJ, BCJ2, Delta, byte-swap and other branch filters, and AES-256 with
    SHA-256;
  - 7-Zip's decryption routines for RAR 2 to 5 and for WinZip AES
    (CPP/7zip/Crypto: Rar20Crypto, RarAes, Rar5Aes, WzAes, with the HMAC,
    PBKDF2 and SHA-1 code they use).

No RAR decompression code is included: the files under 7-Zip's "unRAR
license restriction" are CPP/7zip/Compress/Rar*, and none of them is
compiled, so that restriction does not apply to this module. Nor are the
BSD-licensed LZFSE, Zstandard and xxHash parts included.
